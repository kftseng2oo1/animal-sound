# 🐾 世界動物叫聲遊戲

給小朋友玩的互動遊戲：點一下動物，聽牠的叫聲和名稱，支援中、英、日、西班牙文四種語言。

**線上使用**：https://kftseng2oo1.github.io/animal-sound/

## 主要功能
- 鴨子、貓咪、小狗、小雞、乳牛、獅子、大象等動物，每隻都有情境提示與擬聲字
- 四種語言：繁體中文、English、日本語、Español，各自有對應的擬聲寫法
- 點擊播放真實叫聲（Freesound 音檔），並用語音合成念出動物名稱
- 音效、星星與彩帶動畫，全部完成後顯示結果畫面，可再玩一次或換語言

## 使用方式
1. 選擇語言
2. 點「按一按我！」聽叫聲，再按「下一隻動物 →」
3. 全部認識完會出現完成畫面

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- Web Audio API（音效）、`speechSynthesis`（念名稱）
- 叫聲音檔來自 `freesound.org`，需連網
- 不儲存任何資料
